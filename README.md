# Starweb Tween

Frame-driven tween manager with easing for the browser, built with TypeScript.

[![CI](https://github.com/starweb-libs/tween/actions/workflows/ci.yml/badge.svg)](https://github.com/starweb-libs/tween/actions/workflows/ci.yml)
[![Library Version](https://img.shields.io/npm/v/@starweb-libs/tween)](https://www.npmjs.com/package/@starweb-libs/tween)

## Modules
| Module    | Description                            |
| ------    | -----------                            |
| `easing`  | Easing functions and lookup table      |
| `manager` | Frame-driven tween manager             |
| `types`   | Tween config, handle, and target types |

## Installation
```bash
npm install github:starweb-libs/tween
```
